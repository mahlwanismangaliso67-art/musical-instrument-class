🎵 Musical Instrument Class – Python OOP

📌 About the Project

This is a beginner Python project focused on practising Object-Oriented Programming (OOP). I created a "MusicalInstrument" class to represent different musical instruments and implemented methods to display messages and return facts about each instrument.

🛠️ Concepts Practised

- Classes and Objects: Created a "MusicalInstrument" class and two instrument objects.
- "__init__()" Method: Initialized each instrument with a name and instrument type.
- Instance Attributes: Stored each instrument's name and family.
- Instance Methods: Created methods to play an instrument and return information about it.
- "print()" and "return": Practised displaying output and returning strings from methods.

🎹 Instruments Used

- Oboe — Woodwind family
- Trumpet — Brass family
